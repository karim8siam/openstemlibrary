§4.1 Unit orientation: definition, construction, and evidence

Core insight. A bijection compares size without choosing a preferred enumeration. Infinite sets exhibit behavior impossible for finite sets. Running case. Two repositories enumerate student submissions differently; ask whether they have equally many identifiers, whether every identifier is processed, and whether missing indices can be repaired. Restriction. For infinite sets, cardinal comparison is not the same as inclusion; a proper subset may have equal cardinality.

An explicit matching is stronger evidence of equinumerosity than the impression that two collections are “both endless.” A bijection includes a rule and a proof of no collisions and no omissions. Its domain and codomain must be named: shifting N forward changes the range, even though the shifted range has the same cardinality.

Dedekind-infinitude exposes a difference between finite and infinite sets. But the background logic matters: without an adequate choice principle, some converse statements about infinite and Dedekind-infinite sets are not provable in ZF alone. A textbook must not silently import a stronger axiom.

Enumerations are algorithms only when the scheduling reaches every intended element and treats duplicates consistently. The enumeration of positive fractions by diagonal level p+q is complete because each pair has a finite level. Infinite grids are easy to draw misleadingly; provide a finite index bound for each target.

Three questions before working. (1) What is the explicit mapping? (2) Can two inputs collide, or can an output be missed? (3) Does the proof accidentally import an axiom of choice?

The unit is organized in a deliberate sequence. Start with a definition; derive consequences by matching the definition to its quantifiers; construct a worked finite or symbolic case; and then search for a boundary case. Mathematics offers different kinds of evidence. A direct proof establishes a result for all objects in the stated domain; a counterexample disproves such a result; an example only illustrates it. The accompanying model visualizations are transparent local computations. They can reveal errors and motivate a proof, but cannot establish set-theoretic independence, consistency, or claims about every possible infinite structure.

Common vocabulary and a formal audit

In this unit, the word construction means a legitimate definition of an object in the chosen system, not just an algorithm that prints a plausible string. The running case is Two repositories enumerate student submissions differently; ask whether they have equally many identifiers, whether every identifier is processed, and whether missing indices can be repaired. A complete mathematical account begins by stating the source sets and background theory. Next specify what is asserted to exist, what equality means for these objects, and what properties need proof. Finally separate any domain facts collected from outside the mathematics. The last separation matters because an algorithm can be logically correct yet operate on incomplete or incorrectly classified entries.

A quick error audit starts from the restriction: For infinite sets, cardinal comparison is not the same as inclusion; a proper subset may have equal cardinality. Try to invent a minimal counterexample to a stronger-sounding but invalid statement. If the counterexample is finite, list each member or ordered pair explicitly. If the statement concerns infinity or axioms, name the exact principle that would be required. Giving the missing hypothesis is a mathematically useful response: it tells the reader how the claim could be repaired without pretending it was already proved.

§4.2 Bijections and equal cardinality

Statement and formal objects

Definition. Sets A and B are equinumerous, A≈B, when a bijection f:A→B exists. A bijection is injective (one-to-one) and surjective (onto), not just one of these. The object under discussion is not a mere metaphor: its elements, domain, equality condition, and allowable constructions determine what can be deduced. In particular, a statement with a universal quantifier must be justified for every member of its stated domain. A statement of existence requires an actual object or a valid existence theorem. Wherever notation abbreviates a more detailed membership claim, unfold it before applying a familiar algebraic rule.

Fully worked example

Worked case. f:Z→Z, f(n)=n+1, is a bijection even though it shifts every integer. For N={0,1,...}, g(n)=2n bijects N with the proper subset of even naturals. To check this example, first record exactly the input set or structure. Then perform each step under the definition rather than under a visual intuition. If the result is a set, an elementwise membership test is the primary certificate; if it is a map, check both uniqueness and totality; if it is a formal theorem, identify the inference used. The example shows the stated calculation in this setting. It does not, by itself, justify replacing finite inputs with arbitrary infinite ones.

A tempting error. Concluding two infinite sets have unequal size because one is a strict subset of the other. Diagnose it by writing the disputed expression and the legal definition next to each other. Test a small counterexample when one exists; otherwise state the missing justification. A successful correction is not simply a more forceful verbal explanation. It should alter a quantified claim, a domain declaration, an equality condition, or a proof step that has been shown to be wrong. If the same error can survive the revised formulation, the repair is not complete.

Three graded exercises and answer guidance

Exercise 1 — derive. Build an explicit bijection between N and the positive odd integers, and write its inverse. Worked answer or proof outline: f(n)=2n+1, with inverse f⁻¹(2n+1)=n on the odd positives. Directly test injectivity and surjectivity. Check each intermediate membership or mapping fact. If more than one construction is possible, explain what property the chosen one has that matters for the problem. A good answer can be verified by somebody who does not know the intended conclusion in advance: the definition and the visible steps suffice.

Exercise 2 — find a countercase. Analyze the claim implicit in the mistake: Concluding two infinite sets have unequal size because one is a strict subset of the other. Construct the smallest useful finite case or supply an axiom-level diagnosis. Answer check: the proposed failure must share the same domain and hypotheses as the original claim. A picture with omitted cases is not a counterexample. When no counterexample is appropriate because the result is itself a theorem, explain why the attempted move is invalid without asserting a fabricated example. Describe which condition is essential to the valid statement.

Exercise 3 — transfer. Apply the definition to the unit project: Two repositories enumerate student submissions differently; ask whether they have equally many identifiers, whether every identifier is processed, and whether missing indices can be repaired. Start by assigning mathematical types to the represented objects, then state whether the operation being requested preserves those types. Answer check: identify one ordinary input and one edge case, such as an empty relation, duplicate identifier, missing output, undefined ambient set or a new ordinal stage. §4.7 Unit 4 integrative capstone — Bijections and Infinite Sets

Project brief. Two repositories enumerate student submissions differently; ask whether they have equally many identifiers, whether every identifier is processed, and whether missing indices can be repaired. Draft a mathematics-first specification. Begin with the minimum object vocabulary for the case: distinguish an element, a collection of elements, a relation, a function and a predicate where relevant. Then select at least two of the five lesson theorems or constructions and explain precisely how they apply. Include one counterexample to a tempting informal rule. A valid submission must not imply that a finite output validates an unlimited set-theoretic law.

Proof deliverables. 1. A source-set and ambient-universe declaration that resolves what is the explicit mapping? 2. A worked calculation that can be independently repeated without external data. 3. A statement of whether the central result is an identity, an existence claim, an injection, a well-ordering argument, an induction theorem, or an independence statement. 4. An edge-case analysis respecting the warning: For infinite sets, cardinal comparison is not the same as inclusion; a proper subset may have equal cardinality. 5. A final paragraph explaining what remains outside the proof.

Marking rubric (100 points). Exact mathematical objects and domains: 20. Correct use of definitions: 20. Verifiable worked argument: 25. Counterexample and limitations: 20. Clarity, notation and citation of background assumptions: 15. An answer loses foundational credit when it conflates a set and its element, treats a limited search as a universal result, assumes a function is invertible without proof, or omits a limit-stage or choice assumption that affects the result.

Unit-level short examination

Question A. Compare the hypotheses and conclusions of Bijections and equal cardinality and Hilbert hotel and complete assignments. Give a concrete condition under which the second topic requires extra reasoning not supplied by the first.

Question B. Rebuild a nontrivial example from scratch while changing the original numerical identifiers or relation table. Check the result using the same definition, and explain why the identity of the symbols does not matter when an isomorphism or renaming preserves the relevant structure.

Question C. State which named axiom or principle would justify an existence statement in the unit and which statements can be proved from definitions alone. Carefully separate the informal application from a statement inside classical set theory.

Question D. Identify one realistic reason a software implementation of this unit’s ideas could be wrong even if its core mathematics is sound; propose a test for the implementation without claiming that the test proves a theorem about infinity.
