Verification, Model Comparison and Reporting

Comprehensive university textbook unit covering fundamental theory, mathematical derivations, numerical modeling, and design validation of Verification, Model Comparison and Reporting. Developed for undergraduate civil engineering study.

About this textbook. Original English teaching material for university Structural Analysis I study. Eight units with verified worked problems and 16 interactive simulations illustrating fundamental principles and core applications. Numerical checks and an editorial review support this edition.

§8.1 Unit purpose

Unit purpose

Verification is the bridge between doing algebra and producing a usable structural calculation. Checking more digits does not cure the wrong model. Reliable work combines conservation laws, compatibility, benchmark comparisons, numerical convergence and transparent documentation.

§8.2 Field scenario

Field scenario

Build a mini verification plan for a local footbridge model: decide which assumptions need photographs or drawings, which numbers need independent calculations, and which uncertainties cannot be resolved by a spreadsheet alone.

§8.3 Topics and worked reasoning

Topics and worked reasoning

Topic 8.1: Equilibrium and compatibility residuals

Numerical answers must satisfy all equations that define the selected model, not merely look plausible. For a determinate beam compute vertical force and moment residuals after solving reactions. For a truss compute the vector residual at each joint, ideally scaled by a representative applied load. For a beam with imposed displacement compute the difference between predicted and prescribed support deflection. Large residuals may signal unit inconsistency, a sign mistake, an unconstrained degree of freedom or an implementation error.

Engineering practice: Create a verification table showing each residual, its normalization and an acceptance tolerance. Distinguish floating-point rounding, discretization error and modeling error. A zero residual cannot prove the assumed support behavior is physically correct; it proves only internal consistency for the specified equations.

Fully evaluated study example

To verify a beam of span 8.0 m carrying P=24 kN at x=5.5 m and w=0.9 kN/m, compute RA=11.100 kN and RB=20.100 kN independently from opposite moment balances. The applied vertical force total is 31.200 kN; the reaction total is 31.200 kN. Both totals agree. A second solver that uses the same incorrect load input may still pass this check, so geometry validation and an external load schedule remain essential.

Reasoning and interpretation

What are the exact equilibrium and compatibility residuals? Start by writing the physical reason, then use an equation or laboratory parameter sweep to support the claim. Compare the result against an extreme case: zero applied load, negligible rise, very long span, perfectly fixed restraint, or load at a support, whichever is physically appropriate. In a valid limiting case, the response should approach a predictable behavior. When a calculation fails an extreme-case check, investigate modeling assumptions before blaming numerical precision.

Topic 8.2: Sensitivity and idealization limits

A structural output can be highly sensitive to certain model choices. In a simple beam, flexural deflection varies inversely with EI, but reaction distribution does not. In a propped cantilever with settlement, reaction distribution depends on stiffness and support movement. In a shallow arch, horizontal thrust varies inversely with rise. These parameter sensitivities are useful diagnostic tests and can reveal unrealistic designs or data errors before detailed analysis. Sensitivity to material stiffness and sensitivity to geometry are distinct questions.

Engineering practice: Perturb at least three independent inputs by a small percentage and report the relative response change. Identify a case where the response is nonlinear in the parameter and explain why a linear extrapolation is misleading. Make sure a sensitivity study retains consistent units, boundary conditions and load directions.

Topic 8.3: Closed-form versus numerical models

A numerical beam model approximates a continuous structure by discrete degrees of freedom and elements. For a simple linear beam with constant stiffness, exact element stiffness relations can reproduce certain nodal responses with very few elements, while recovering distributed-load curvature and local field response may require careful consistent loading and interpolation. A converged numerical result should be compared with a known closed-form benchmark where possible. Using a finer mesh without checking the model equations, boundary conditions or input units is not sufficient verification.

Engineering practice: Compare an integration-based deflection result with a numerical quadrature approximation or a stiffness-method calculation. Refine the numerical representation and plot error against number of divisions. State the reference solution, input values, convergence criterion and remaining discrepancies. A visually smooth plot should not be taken as evidence of numerical accuracy.

Topic 8.4: Engineering communication and reproducibility

A defensible structural calculation communicates geometry, load cases, sign conventions, units, support idealizations, material properties, method selection, checks and limitations. It separates model inputs from computed responses and design acceptance criteria. Versioned analytical scripts, traceable parameter values and explicit test cases make independent reproduction possible. This volume teaches preliminary elastic structural analysis rather than jurisdiction-specific design checking. Load factors, material resistance factors and detailing rules depend on authoritative codes and cannot be invented from the formulas in a teaching lab.

Engineering practice: Write a one-page calculation note for a hypothetical pedestrian bridge: define the question, assumptions, load transfer, beam or truss model, critical response, verification check and next required investigations. Add a limitation statement about omitted vibration, foundation behavior, fatigue or connection stiffness. A useful report presents uncertainty and scope rather than attaching false precision to a single number.

§8.4 Deep dive and misconception repair

Deep dive and misconception repair

Verification clinic: use independent equations and independent models

Verification begins with a question about what could be wrong. A spreadsheet that gives a smooth graph may contain a sign reversal, a unit conversion mistake or an incorrect boundary condition. Global equilibrium residuals detect some of these defects, but not all. A simple-beam calculation with an incorrect point-load location can still satisfy equilibrium with respect to the incorrect input. Therefore verification has layers: first validate the geometry and load schedule, then check the analytical equations, then test the numerical implementation and finally compare response against observed physical plausibility.

Residuals should be normalized where useful. A vertical equilibrium difference of 0.001 kN is negligible for an example with 100 kN total applied load but may be significant for a highly sensitive micro-scale instrument. A relative residual divides the absolute imbalance by a meaningful characteristic load, while an absolute residual provides the physical units. Report both if decisions depend on tolerances. In joint-equilibrium analysis of a truss, check horizontal and vertical closure at every node to locate the specific joint where a sign or direction-cosine error appears.

Numerical convergence is a separate issue. A midpoint quadrature of a smooth virtual-work integrand should approach the analytic result as the segment count increases. An incorrect integrand may also converge, but to the wrong value. That is why a known exact benchmark is valuable. Conversely, if a model uses physically meaningful irregular geometry and no closed form is available, compare against a simpler limiting case and independently check global conservation.

Sensitivity without invented precision

A sensitivity study should identify whether uncertainty in geometry, stiffness, loading or supports dominates the answer. Small span errors can have an amplified effect on distributed-load deflection because span enters to the fourth power. The same stiffness uncertainty leaves a determinate beam reaction unchanged while altering displacement. Support settlement changes an indeterminate reaction in proportion to EI. These are mechanistic comparisons, not statistical uncertainty estimates; to quantify probability one would need justified distributions for uncertain inputs.

Engineering documentation is part of the calculation. A reproducible note states what coordinate system is used, what direction counts as positive, what force and length units are used, which loads act simultaneously, what restraints are applied and what idealizations are excluded. It provides the governing equations, numerical values and at least one independent closure check. If a program produces a plot and downloadable CSV data, record its version and input settings so the figures can be regenerated later.

The calculations in this book are for educational elastic analysis. They are not code design checks. A bridge, building or foundation requires an appropriate local standard, load combinations, material resistance models, serviceability criteria and competent engineering review. A report that omits this scope boundary risks inviting misuse. The strongest report is not the one that hides limitations; it is the one that states exactly what has and has not been established.

Project brief

The note must include a problem definition, a labeled free-body diagram, a parameter and unit table, equations, at least two worked numerical results, an independently evaluated check, a figure or CSV trace from a linked simulation, and a discussion of three limitations.
