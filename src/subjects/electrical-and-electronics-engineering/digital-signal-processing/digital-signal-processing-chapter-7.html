§7.6 Analytical Derivations and Assessment: Finite Register Length Effects, Coefficient Quantization, and Roundoff Noise

Unit 7 capstone — Feature extraction under uncertainty

Engineering problem

Generate weak periodic tones plus seeded broadband noise, compare raw and Welch PSD estimates, and evaluate features against false-alarm and sensitivity requirements. The capstone intentionally uses invented signals, not field measurements. The unit provides the mathematical concepts: Periodogram normalization and units, Welch averaging and estimator variance, Harmonics and spectral peak discrimination, Envelope, cepstrum and modulation features, Time-frequency localization and feature reliability. Write a concise problem statement and choose consistent notation for time, sample index, physical units and the transform convention. Keep raw input parameters in a table separate from derived outputs.

Required submissions

  1. A mathematical model listing all assumptions, independent variables and initial conditions or finite record lengths.
  2. A hand-verifiable result with the steps from governing equation to value or functional expression.
  3. One independent computation, using a different method from the hand calculation, with an explicit discrepancy tolerance.
  4. A plot that labels units, sample rate, window and phase/frequency conventions when relevant.
  5. Two stress tests: one boundary case and one deliberate model violation with the expected failure symptoms.
  6. A short engineering report distinguishing verification of code from validation against physical data.

Evaluation rubric (100 points)

  • Mathematical and physical specification: 20.
  • Correct derivations and units: 25.
  • Independently reproducible numerical result: 20.
  • Boundary and violation tests: 20.
  • Clear interpretation and data provenance: 15.

Discussion prompts

Explain why your assumptions are necessary; demonstrate whether changing the record length or excitation changes the result; discuss which error is numerical and which is modeling error; and propose a minimal real-world test to determine whether the simplified model is appropriate. A visually convincing trace without a numeric reference earns no numerical verification credit. Refer to the corresponding lessons for the domain-specific limitations.
