§6.1 Ideal op-amp constraints and negative feedback

Unit 6, Lesson 1: Ideal op-amp constraints and negative feedback

Model: V+≈V− when linear, stable negative feedback Outcome: Analyze the operating principle, calculate a reference case, identify the limit of the approximation, and plan an independent check.

Physical mechanism

An op amp magnifies the difference between its input terminals. High open-loop gain plus properly connected negative feedback can force that difference to a small value. Virtual equality does not mean current can flow directly between input terminals. The approximation fails when the amplifier clips, violates its common-mode range, slews too slowly or becomes unstable.

Draw the relevant circuit or band diagram and name the source of energy, the signal that controls the result, the return path and the reference directions. A model of an individual element must be used with conservation of current and voltage around the complete circuit. This distinction is critical because a device characteristic measured under one set of bias conditions may not hold with a different load. Describe which parameters are external controls and which are intrinsic or empirical device parameters. In operational amplifiers and active functions, an especially important issue is closed-loop constraints; make it explicit before calculating anything.

Derivation and calculation

Start from V+≈V− when linear, stable negative feedback. Explain the assumptions required to use the expression and distinguish DC current, incremental gain, instantaneous waveform, average power and RMS quantities wherever they arise. If the expression is nonlinear, first identify the valid region; if it is an incremental result, identify the linearization point. An elegant equation is not proof that the circuit's bias or signal swing permits the result.

Worked example. With open-loop gain 10^5 and unsaturated output 2 V, the differential input is around 20 μV. This is not a guarantee of zero input offset.

§6.2 Inverting and non-inverting amplifier design

Model: Av,inv≈−Rf/Rin; Av,non≈1+Rf/Rg Outcome: Analyze the operating principle, calculate a reference case, identify the limit of the approximation, and plan an independent check.

Physical mechanism

The inverting topology holds a summing node near a reference through feedback and develops an output proportional to input through a resistor ratio. The non-inverting topology uses feedback division and has high nominal input impedance. Resistor matching affects closed-loop gain accuracy and input bias current may produce DC output error.

§6.3 Summing, differential and instrumentation stages

Unit 6, Lesson 3: Summing, differential and instrumentation stages

Model: Vo≈−Rf Σ(Vi/Ri) Outcome: Analyze the operating principle, calculate a reference case, identify the limit of the approximation, and plan an independent check.

Physical mechanism

An op-amp summing node permits weighted analog addition, but every input drives through an impedance that must be included in the loading calculation. A differential stage subtracts two signals; its rejection of common-mode voltage depends on resistor-ratio matching. Instrumentation amplifiers increase input impedance and can improve common-mode rejection while retaining programmable gain.

§6.4 Integrators and differentiators

Unit 6, Lesson 4: Integrators and differentiators

Model: Vo(t)=−(1/RC)∫Vi(t)dt Outcome: Analyze the operating principle, calculate a reference case, identify the limit of the approximation, and plan an independent check.

Physical mechanism

An ideal inverting integrator accumulates input over time using feedback capacitance. A differentiator emphasizes rapid input changes but can amplify high-frequency noise. Practical integrators require DC feedback leakage paths or reset controls to prevent tiny offsets from driving output saturation. Practical differentiators limit both low and high frequency gains.

§6.5 Active filters and frequency response

Unit 6, Lesson 5: Active filters and frequency response

Model: |H(f)|=A0/sqrt(1+(f/fc)²) Outcome: Analyze the operating principle, calculate a reference case, identify the limit of the approximation, and plan an independent check.

Physical mechanism

A first-order low-pass stage passes lower frequencies and increasingly attenuates higher frequencies, with a phase lag approaching 90 degrees in the ideal limit. Active realizations use an amplifier to buffer or provide gain but may be restricted by amplifier bandwidth. Cascading sections changes order and the shape near cutoff.
