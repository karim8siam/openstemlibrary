§2.1 Per-unit representation

Unit 2, lesson 1: Per-unit representation

Learning objectives: analyze base power, base voltage, base impedance, base current, base conversion; interpret Z_base = V_LL,base^2 / S_3phase,base ; Z_pu = Z_ohm / Z_base and report valid application limits.

1. The physical system

Engineering models are useful only after voltage bases, reference directions, equivalent-circuit assumptions and conversion conventions are fixed. The same physical impedance has different numerical per-unit values on different bases. Transformer connections and line charging can be decisive even when first-pass calculations neglect them. The topic Per-unit representation concerns base power, base voltage, base impedance, base current, base conversion. An analyst must decide which variables are directly measured and which are inferred from a network equivalent. Sketch the equipment and specify its boundary, phase reference, operating condition and sign convention. Identify the path that carries energy through the system and explain what would change if a switch state, load characteristic or source excitation were different.

In this setting, base power describes a distinct physical aspect from base voltage. Mixing them obscures whether the result depends on component values or system operation. Start with the equipment location and an inventory of observed voltage, current, power, time or geometry as appropriate. Then explain why the simplified relation is sufficient for the particular question being asked, rather than assuming it describes all possible network states.

2. Mathematical formulation

Working relation: Z_base = V_LL,base^2 / S_3phase,base ; Z_pu = Z_ohm / Z_base.

Trace each variable to a specified input or a calculated intermediate quantity. Where a phasor is used, distinguish rms magnitude and complex phase; where a network is balanced, say so explicitly; where a per-unit base is used, specify base MVA and line-to-line base kV. Note that mathematical equivalence does not establish physical validity: a fitted impedance is an effective model at a given frequency, temperature and topology, while the equipment rating sets additional limits beyond the equation.

Evaluate limiting cases that apply to the stated relation: reduced load, increased impedance, vanishing angle difference, or alternative grounding. Do not apply all these checks indiscriminately; choose two that make physical sense here. Check that the result has units consistent with base power and that conversion between MW, MVA, kV, A, ohms and per-unit values has been performed correctly. The result should be reproducible from the written assumptions without guessing any hidden convention.

3. Worked calculation

Example. On 100 MVA and 132 kV three-phase bases, Z_base is 174.24 ohm; a 17.424 ohm reactance is 0.10 pu.

Interpretation. Base voltage is line-to-line for the three-phase impedance base and base power is total three-phase power. For independent verification, re-evaluate the stated numerical inputs using the working relation and compare to the quoted magnitude. Record whether the calculated result is a steady-state operating point, an initial symmetrical fault estimate, a long-term energy statistic or a purely geometric property. Re-run the example with a ten-percent change in its principal variable, and explain why that percentage change in the input does not necessarily yield the same percentage change in the output.

Why precision matters. Do not compare an approximate computation with a nameplate limit by simply treating all of the presented digits as exact. A load measurement may have a sampling interval, a component impedance depends on conditions, and an ideal transformer omits losses. If the result is close to a design limit, obtain verified measurements and a more complete model before concluding that a configuration is feasible.

4. Reliability of the approximation

Common technical mistake: Mixing 11 kV and 132 kV bases across a transformer without a matching ratio invalidates impedance combinations.

Verification procedure: Build a two-base table showing 33 kV and 132 kV sides; recompute a physical impedance and confirm identical component predictions. Write a minimal input ledger that records variable name, value, SI unit, data source, time and uncertainty. Select one independent calculation, measurement or conserved quantity with which to check the result. If the two approaches disagree, determine whether the difference comes from sign conventions, base changes, a model omitted term, poor timing alignment or a calculation error. This is an essential distinction: a numerically stable solver can still give a wrong answer when it solves the wrong network.

Before relying on per-unit representation for equipment selection, establish the relevant continuous rating, short-time limit and the applicable operating constraints. For models with no dynamic terms, identify at least one fast disturbance they cannot predict. For models based on averages, identify at least one short interval where the average hides a high-risk condition. State the evidence still missing, rather than claiming that numerical plausibility proves system safety or reliability.

5. Applied case study

Engineering problem. A fault study combines a generator reactance on its nameplate MVA with a cable reactance on a system base; correct it without discarding the useful original data.

Prepare two competing hypotheses for the scenario. Under the first, the original proposal is acceptable given the displayed model and assumed input range. Under the second, another loading condition, equipment limit, network state or source behavior reverses the conclusion. Design a controlled numerical experiment that would distinguish them: choose a measurable output, make one intentional parameter change at a time and hold all other stated quantities fixed. Explain when holding a variable fixed would be unrealistic because it is coupled to the changed parameter.

Finally, produce a short decision memo with a numerical range, not merely a single estimate. Include a base case, adverse case and data-quality concern related to base conversion. Report whether the simplified model is sufficient for teaching, preliminary screening or detailed engineering. If it is not sufficient, name the additional circuit, measurement or operational constraint that would be required.

6. Questions and guided responses

1. Physical reasoning. How are base power and base voltage connected in this model? *Guidance:* start with the labelled boundary, name both units and identify the causal path rather than merely repeating a formula.

2. Numerical problem. Recalculate the example using `Z_base = V_LL,base^2 / S_3phase,base ; Z_pu = Z_ohm / Z_base` and then increase its principal source or load input by ten percent. *Guidance:* report both numerical values, check signs and dimensions and explain the relevant nonlinear terms.

3. Model validity. Give two conditions under which the relation may cease to be accurate for per-unit representation. *Guidance:* distinguish omitted physical mechanisms from bad data and specify an independent test.

4. Design judgment. Apply the relation to the case study and explain what one additional observation would change your decision. *Guidance:* compare equipment limits with credible normal and contingency operating states.

5. Cross-topic reasoning. Explain how base conversion would affect one other lesson in Unit 2. *Guidance:* name the shared state variable and show how the same value propagates to a separate mathematical model.

7. Study extension

Build a small sensitivity table: base case, 90-percent value of the most uncertain input, 110-percent value and one changed equipment or topology configuration. For each row, first predict the direction of the output change and then calculate it. Write a brief explanation for any result that does not follow your prediction. Mark a case “outside model validity” if its assumptions are contradicted, instead of forcing the calculation to produce a persuasive number. The goal is to understand both the use and limits of per-unit representation in an interconnected electrical system.
