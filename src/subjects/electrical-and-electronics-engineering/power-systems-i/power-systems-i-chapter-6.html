§6.1 Demand forecasting and load duration

Unit 6, lesson 1: Demand forecasting and load duration

Learning objectives: analyze hourly forecast, peaks, weather, customer mix, load-duration curve; interpret Forecast error = actual demand - predicted demand; MAPE requires nonzero actual values and report valid application limits.

1. The physical system

Energy accounting explains how load and generation profiles become operating schedules. Economics affects which units run, but a least-cost schedule is not feasible if voltage, line, ramping, reserve or minimum-generation limits are ignored. Time resolution should be chosen according to the phenomenon under study. The topic Demand forecasting and load duration concerns hourly forecast, peaks, weather, customer mix, load-duration curve. An analyst must decide which variables are directly measured and which are inferred from a network equivalent. Sketch the equipment and specify its boundary, phase reference, operating condition and sign convention. Identify the path that carries energy through the system and explain what would change if a switch state, load characteristic or source excitation were different.

In this setting, hourly forecast describes a distinct physical aspect from peaks. Mixing them obscures whether the result depends on component values or system operation. Start with the equipment location and an inventory of observed voltage, current, power, time or geometry as appropriate. Then explain why the simplified relation is sufficient for the particular question being asked, rather than assuming it describes all possible network states.

2. Mathematical formulation

Working relation: Forecast error = actual demand - predicted demand; MAPE requires nonzero actual values.

Trace each variable to a specified input or a calculated intermediate quantity. Where a phasor is used, distinguish rms magnitude and complex phase; where a network is balanced, say so explicitly; where a per-unit base is used, specify base MVA and line-to-line base kV. Note that mathematical equivalence does not establish physical validity: a fitted impedance is an effective model at a given frequency, temperature and topology, while the equipment rating sets additional limits beyond the equation.

Evaluate limiting cases that apply to the stated relation: reduced load, increased impedance, vanishing angle difference, or alternative grounding. Do not apply all these checks indiscriminately; choose two that make physical sense here. Check that the result has units consistent with hourly forecast and that conversion between MW, MVA, kV, A, ohms and per-unit values has been performed correctly. The result should be reproducible from the written assumptions without guessing any hidden convention.

3. Worked calculation

Example. Predictions 90, 100, 110 MW against actual 95, 98, 112 MW have errors +5, -2 and +2 MW using the actual-minus-forecast convention.

Interpretation. A load-duration curve sorts loads by magnitude and therefore loses the original time sequence. For independent verification, re-evaluate the stated numerical inputs using the working relation and compare to the quoted magnitude. Record whether the calculated result is a steady-state operating point, an initial symmetrical fault estimate, a long-term energy statistic or a purely geometric property. Re-run the example with a ten-percent change in its principal variable, and explain why that percentage change in the input does not necessarily yield the same percentage change in the output.

Why precision matters. Do not compare an approximate computation with a nameplate limit by simply treating all of the presented digits as exact. A load measurement may have a sampling interval, a component impedance depends on conditions, and an ideal transformer omits losses. If the result is close to a design limit, obtain verified measurements and a more complete model before concluding that a configuration is feasible.

4. Reliability of the approximation

Common technical mistake: A good annual energy forecast can still miss peak timing and create a serious adequacy error.

Verification procedure: Compare mean absolute error, maximum positive error and peak-hour bias of two forecast models. Write a minimal input ledger that records variable name, value, SI unit, data source, time and uncertainty. Select one independent calculation, measurement or conserved quantity with which to check the result. If the two approaches disagree, determine whether the difference comes from sign conventions, base changes, a model omitted term, poor timing alignment or a calculation error. This is an essential distinction: a numerically stable solver can still give a wrong answer when it solves the wrong network.

Before relying on demand forecasting and load duration for equipment selection, establish the relevant continuous rating, short-time limit and the applicable operating constraints. For models with no dynamic terms, identify at least one fast disturbance they cannot predict. For models based on averages, identify at least one short interval where the average hides a high-risk condition. State the evidence still missing, rather than claiming that numerical plausibility proves system safety or reliability.

5. Applied case study

Engineering problem. A solar-rich area reports a lower average demand forecast error but more severe evening ramps; decide which statistic matters for reserves.

Finally, produce a short decision memo with a numerical range, not merely a single estimate. Include a base case, adverse case and data-quality concern related to load-duration curve. Report whether the simplified model is sufficient for teaching, preliminary screening or detailed engineering. If it is not sufficient, name the additional circuit, measurement or operational constraint that would be required.
