§5.1 Balanced three-phase short circuits

Unit 5, lesson 1: Balanced three-phase short circuits

Learning objectives: analyze positive-sequence Thevenin equivalent, prefault voltage, subtransient reactance, initial current; interpret I_3ph = V_prefault_phase / Z_Thevenin_positive and report valid application limits.

1. The physical system

Short-circuit estimates support protective-device studies, but a basic source-plus-impedance model omits dc offsets, time dependence, grounding details, frequency response, equipment tolerances and arc behavior. Fault studies are not a replacement for qualified protective coordination and safety procedures. The topic Balanced three-phase short circuits concerns positive-sequence Thevenin equivalent, prefault voltage, subtransient reactance, initial current. An analyst must decide which variables are directly measured and which are inferred from a network equivalent. Sketch the equipment and specify its boundary, phase reference, operating condition and sign convention. Identify the path that carries energy through the system and explain what would change if a switch state, load characteristic or source excitation were different.

In this setting, positive-sequence Thevenin equivalent describes a distinct physical aspect from prefault voltage. Mixing them obscures whether the result depends on component values or system operation. Start with the equipment location and an inventory of observed voltage, current, power, time or geometry as appropriate. Then explain why the simplified relation is sufficient for the particular question being asked, rather than assuming it describes all possible network states.

2. Mathematical formulation

Working relation: I_3ph = V_prefault_phase / Z_Thevenin_positive.

Trace each variable to a specified input or a calculated intermediate quantity. Where a phasor is used, distinguish rms magnitude and complex phase; where a network is balanced, say so explicitly; where a per-unit base is used, specify base MVA and line-to-line base kV. Note that mathematical equivalence does not establish physical validity: a fitted impedance is an effective model at a given frequency, temperature and topology, while the equipment rating sets additional limits beyond the equation.

Evaluate limiting cases that apply to the stated relation: reduced load, increased impedance, vanishing angle difference, or alternative grounding. Do not apply all these checks indiscriminately; choose two that make physical sense here. Check that the result has units consistent with positive-sequence Thevenin equivalent and that conversion between MW, MVA, kV, A, ohms and per-unit values has been performed correctly. The result should be reproducible from the written assumptions without guessing any hidden convention.

3. Worked calculation

Example. At 11 kV, Z_th=j2 ohm per phase and prefault voltage is 11/sqrt(3) kV, so the rms symmetrical initial fault-current magnitude is about 3.18 kA.

Interpretation. A three-phase balanced short circuit can be estimated entirely from a positive-sequence network. For independent verification, re-evaluate the stated numerical inputs using the working relation and compare to the quoted magnitude. Record whether the calculated result is a steady-state operating point, an initial symmetrical fault estimate, a long-term energy statistic or a purely geometric property. Re-run the example with a ten-percent change in its principal variable, and explain why that percentage change in the input does not necessarily yield the same percentage change in the output.

Why precision matters. Do not compare an approximate computation with a nameplate limit by simply treating all of the presented digits as exact. A load measurement may have a sampling interval, a component impedance depends on conditions, and an ideal transformer omits losses. If the result is close to a design limit, obtain verified measurements and a more complete model before concluding that a configuration is feasible.

4. Reliability of the approximation

Common technical mistake: The rms symmetrical current is not the same as instantaneous peak making current or interrupting duty.

Verification procedure: Vary source reactance and compare short-circuit MVA for a consistent rated voltage. Write a minimal input ledger that records variable name, value, SI unit, data source, time and uncertainty. Select one independent calculation, measurement or conserved quantity with which to check the result. If the two approaches disagree, determine whether the difference comes from sign conventions, base changes, a model omitted term, poor timing alignment or a calculation error. This is an essential distinction: a numerically stable solver can still give a wrong answer when it solves the wrong network.

Before relying on balanced three-phase short circuits for equipment selection, establish the relevant continuous rating, short-time limit and the applicable operating constraints. For models with no dynamic terms, identify at least one fast disturbance they cannot predict. For models based on averages, identify at least one short interval where the average hides a high-risk condition. State the evidence still missing, rather than claiming that numerical plausibility proves system safety or reliability.
