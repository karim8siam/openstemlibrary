§6.1 Theoretical Overview: Channel Capacity, Mutual Information, and Shannon Noisy-Channel Coding Theorem

Unit 6 — Multiple access and synchronization

Why this unit exists

The unit centers on multiuser field-monitoring network, where many low-power remote stations periodically report data to a shared collector. Its controlling difficulty is that contention, power imbalance and receiver synchronization dominate crowded periods. The four lessons isolate different parts of the mechanism, yet the delivered system must satisfy all of them at once. You will link equations to implementation, design measurements and deliberately test situations in which a convenient idealization becomes misleading.

Concept sequence

Lesson 6.1 — Direct-sequence spreading and processing gain

Spread spectrum distributes each narrowband data symbol across multiple chips and then despreads it by correlation with a matched sequence. Despreading strengthens a correctly aligned desired signal relative to certain uncorrelated narrowband interferers, but it cannot create signal energy. Chip timing must be aligned for the correlation peak. The code autocorrelation sidelobes and received interference statistics determine effective performance. Security or privacy must not be inferred from an easily observed spreading sequence.

Key relation: Multiplying a data symbol by an N-chip ±1 spreading sequence increases occupied chip rate; nominal processing gain is 10log10(N) dB when chip and symbol periods satisfy Tc=Ts/N.

Design boundary: The processing-gain ratio is not automatically a net SNR gain in additive white noise after a matched receiver when transmit energy per bit is held constant.

Lesson 6.2 — Code division and the near-far problem

Code division multiple access assigns distinguishable signatures to users occupying overlapping time-frequency resources. Ideal orthogonality is possible under tight synchronization and specific sequences, but asynchronous delays, multipath and unequal power destroy it. If one transmitter arrives much more strongly than another, even modest cross-correlation leaks excessive interference into the weak user's detector. Closed-loop power control, multiuser detection and interference cancellation are possible mitigations, each with stability, latency and estimation costs.

Key relation: In a two-user spread-spectrum receiver, the undesired despread amplitude is proportional to sqrt(P_interference) times code cross-correlation; near-far imbalance can dominate small correlation values.

Design boundary: Power-control error and capture effect interact with receiver dynamic range; a digital multiuser detector cannot recover an ADC signal that has already saturated.

Lesson 6.3 — Timing acquisition and synchronization loops

Frame timing estimates where a candidate packet begins; symbol timing estimates the sampling phase that captures pulse energy while suppressing ISI. A preamble correlation peak provides a useful acquisition marker but can be blurred by multipath and repeated pattern ambiguity. Fine tracking commonly uses timing error detectors within a feedback loop. Error detector gain depends on pulse shape and SNR. The loop cannot choose arbitrary speed: wide bandwidth follows drift but passes more jitter, while narrow bandwidth filters noise at the cost of slower acquisition.

Key relation: For a known preamble p[n], acquisition can maximize |sum_n r[n+m]p*[n]| over candidate delays m; the strongest peak need not equal the earliest propagation path.

Design boundary: A high correlation peak can occur at a delayed echo; earliest-arrival ranging demands more than choosing the global maximum. Interference and sample-rate mismatch can also shift estimates.

Lesson 6.4 — Frequency hopping and coexistence

Frequency hopping can avoid repeatedly occupying the same narrowband interference source when the hop plan and interferer statistics are favorable. The receiver must know or acquire the hop timing and hopping pattern. Slow hopping uses several symbols per hop, while fast hopping can move multiple times per symbol. Regulatory requirements, spectral masks and available band plans strongly constrain real implementations. This book models abstract signals only and does not suggest transmitting on unlicensed or licensed frequencies without authorization.

Key relation: A hopped carrier takes frequencies from an allowed set according to a time-indexed sequence; dwell duration, hop spacing and synchronization govern interference exposure.

Design boundary: The gain disappears if an interferer follows the sequence or covers the full hopping band. Some coexistence systems need sensing and coordination rather than purely pseudo-random hopping.

Integrated case study

An engineer reviews the architecture for multiuser field-monitoring network. The first review identifies the performance or integrity quantity at the receiver. The second asks which subsystem can change that quantity. The third checks the impact on user payload, energy consumption, delay and operating cost. A favorable conclusion requires comparable conditions; changing both the channel model and signal power while comparing decoders makes it impossible to attribute improvement to one change.

Three-stage assessment plan

1. Analytical baseline. Derive a transparent relation using one of the four listed key models. Describe the allowed parameter region, units and what was held constant in the comparison. For multiuser field-monitoring network, decide which model variable is realistically measurable and which must be inferred.

2. Synthetic controlled test. Isolate one impairment, vary its magnitude and compare to the baseline. Re-run with a different seed and a second numerical implementation. Build a plot with labeled axes and, for error probabilities, uncertainty intervals.

3. Engineering hand-off. Replace the idealized assumption with a more plausible impairment relevant to many low-power remote stations periodically report data to a shared collector. State which earlier conclusion remains reliable and which needs further data. Record what must be checked before a prototype is trusted outside the laboratory.

Unit questions

  • Which of the four mechanisms is most likely to control acceptance for multiuser field-monitoring network, and what measured evidence would establish that claim?
  • How would the design fail if the assumption “The processing-gain ratio is not automatically a net SNR gain in additive white noise after a matched receiver when transmit energy per bit is held constant.” were ignored?
  • Identify a numerical sanity check, an implementation test, and a separate real-world validation requirement.
  • Where would additional redundancy help and where might it merely increase latency or occupy already-limited bandwidth?

Suggested learning order

Read the four lessons in order; complete the simulation, then submit the project with a result table and the associated limitations.

Fully explained example and verification

If a transmitter spends equal time across 20 channels and one channel has persistent interference, the expected fraction of hops landing on that channel is 1/20=5%, assuming uniform hopping and independence. That estimate does not imply only 5% packet loss, because packet lengths, coding and hop dwell matter.
