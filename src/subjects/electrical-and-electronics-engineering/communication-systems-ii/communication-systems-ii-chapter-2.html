§2.1 Theoretical Overview: Binary Passband Signaling: BASK, BFSK, BPSK, and Coherent Matched Filters

Unit 2 — Modern coding and probabilistic decoding

Why this unit exists

The unit centers on coded low-power spacecraft downlink, where a remote probe sends diagnostic records through a noisy long-distance link. Its controlling difficulty is that bit energy, decode latency and packet loss each constrain the operating mode. The four lessons isolate different parts of the mechanism, yet the delivered system must satisfy all of them at once. You will link equations to implementation, design measurements and deliberately test situations in which a convenient idealization becomes misleading.

Concept sequence

Lesson 2.1 — Log-likelihood ratios and soft information

A hard bit has only a sign, while a log-likelihood ratio preserves confidence. Passing confidence from the demodulator to the decoder allows weak bits to be corrected using parity relationships with other bits. Prior probability enters as an additive log-prior odds term. LLR sign conventions vary across implementations; a decoder built for the opposite convention produces systematic errors. Clipping LLR magnitude may be necessary in fixed-point hardware, but overly aggressive clipping destroys reliability information.

Key relation: For equally likely BPSK symbols x in {+1,-1} over AWGN with noise variance sigma^2, L=log[p(y|+1)/p(y|-1)]=2y/sigma^2.

Design boundary: The formula assumes memoryless Gaussian noise and correctly scaled observations. Channel mismatch, clipping and non-Gaussian interference can make high-magnitude LLRs misleading.

Lesson 2.2 — Sparse parity checks and LDPC iteration

A sparse graph exposes parity structure without explicitly listing all codewords. In sum-product decoding, each variable node combines intrinsic channel LLR with extrinsic messages from neighboring checks; each check sends a constraint-informed update to one variable, excluding that variable's previous contribution. A practical min-sum approximation replaces expensive tanh operations with a signed minimum, often with normalization or offset corrections. Cycles make graph messages dependent, so iterations are approximations rather than independent Bayesian inference.

Key relation: For parity-check matrix H, an LDPC code uses sparse constraints Hc=0; belief propagation exchanges variable-to-check and check-to-variable messages on a Tanner graph.

Design boundary: Short cycles and absorbing sets cause error floors. More iterations can consume time and power without reducing error under poor channel estimates. Never compare LDPC and uncoded BER while silently changing information-bit energy.

Lesson 2.3 — Turbo codes and extrinsic-information exchange

Concatenated convolutional encoders with a permutation can transform relatively short-memory codes into powerful long-block constructions. The interleaver disperses localized input patterns so that a damaging low-weight pattern for one component is less damaging for the other. During decoding, a component separates systematic-channel evidence, input prior and newly learned extrinsic evidence. Sending the entire posterior as a new prior double-counts information and encourages false certainty.

Key relation: Turbo decoding iterates between soft-in/soft-out constituent decoders, exchanging extrinsic LLRs through an interleaver.

Design boundary: Iterative information transfer assumes meaningful extrinsic messages. Short interleavers, correlation between messages, poor termination and quantized arithmetic can harm convergence.

Lesson 2.4 — Polar transforms, frozen positions and CRC-aided decisions

Polar coding relies on the unequal reliability of synthesized bit channels at large block lengths. The transmitter places known values in unreliable positions and information in reliable positions, then applies a structured binary transform. Successive-cancellation decoding conditions successive decisions on earlier decisions, so an early wrong decision may propagate. List decoding keeps several candidates. A CRC appended to the message can help select among list candidates, but a CRC is not magic: incorrectly sized lists or unfavorable channels can still produce block errors.

Key relation: The kernel F=[[1,0],[1,1]] over GF(2) forms Kronecker-power polarization transforms; selected synthetic channels carry information while others are frozen.

Design boundary: A code optimized for one channel reliability ordering may perform poorly on another. Finite-length performance cannot be inferred solely from asymptotic capacity arguments.

Integrated case study

An engineer reviews the architecture for coded low-power spacecraft downlink. The first review identifies the performance or integrity quantity at the receiver. The second asks which subsystem can change that quantity. The third checks the impact on user payload, energy consumption, delay and operating cost. A favorable conclusion requires comparable conditions; changing both the channel model and signal power while comparing decoders makes it impossible to attribute improvement to one change.

Three-stage assessment plan

1. Analytical baseline. Derive a transparent relation using one of the four listed key models. Describe the allowed parameter region, units and what was held constant in the comparison. For coded low-power spacecraft downlink, decide which model variable is realistically measurable and which must be inferred.

2. Synthetic controlled test. Isolate one impairment, vary its magnitude and compare to the baseline. Re-run with a different seed and a second numerical implementation. Build a plot with labeled axes and, for error probabilities, uncertainty intervals.

3. Engineering hand-off. Replace the idealized assumption with a more plausible impairment relevant to a remote probe sends diagnostic records through a noisy long-distance link. State which earlier conclusion remains reliable and which needs further data. Record what must be checked before a prototype is trusted outside the laboratory.

  • Identify a numerical sanity check, an implementation test, and a separate real-world validation requirement.
  • Where would additional redundancy help and where might it merely increase latency or occupy already-limited bandwidth?

Successive-cancellation decoding conditions successive decisions on earlier decisions, so an early wrong decision may propagate. List decoding keeps several candidates. A CRC appended to the message can help select among list candidates, but a CRC is not magic: incorrectly sized lists or unfavorable channels can still produce block errors.

Boundary conditions and common mistakes
