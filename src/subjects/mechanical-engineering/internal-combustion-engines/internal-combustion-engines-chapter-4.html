Solved Problem Example 4.1: Calculation & Verification: Internal Combustion Engines — U04-L01

Problem Statement: The working relation used here is `eta_v = m_air_trapped/(rho_ref * V_d) per relevant induction event.`. Define every variable before substitution, keep a single system of units, and check whether its result should increase or decrease when an input changes. Ask which assumptions make the expression possible: steady conditions, a perfect gas, constant properties, a lumped state, negligible pressure loss or an ideal mechanical linkage may be necessary. If an assumption does not hold in the intended application, identify the direction of the expected deviation when physics permits. When that direction is not clear, do not guess; schedule a measurement or use a higher-fidelity calculation. **Assumed numerical case:** At 1.2 kg/m3, a 0.5 L cylinder reference charge is 0.0006 kg per induction event.

Worked Engineering Derivation:

**Calculation walkthrough:** For a reference density 1.2 kg/m³ and cylinder displacement 0.5 L = 0.0005 m³, the reference air mass is 1.2×0.0005 = 0.0006 kg = 0.60 g per induction event. An observed trapped mass of 0.54 g would imply 0.54/0.60 = 90% on this stated reference basis. The stated values form a hypothetical teaching example and should be recalculated by hand. Interpret the result, including failures **Critical interpretation:** A boosted engine may exceed a reference-at-ambient volumetric efficiency of one. A misleading numerical result can arise even when the arithmetic is perfect: the problem may be a wrong system boundary, an inappropriate reference property, a time-averaged signal used for a crank-angle event, or an unrecorded controller response. Think about the change that would be observed in cylinder pressure, exhaust temperature, manifold state, or brake output if the explanatory mechanism were genuinely active rather than merely correlated with an unrelated change. **Conservation audit:** Start by marking the system boundary on a sketch. Solved Problem Example 4.3: Calculation & Verification: Internal Combustion Engines — U04-L03

Problem Statement: Use `Approximate a simple restriction as Delta p = K * rho * v^2 / 2.` as the initial closure relation. It is tempting to interpret the number as a design guarantee; instead define a reference operating point, perturb each independent input separately and observe the output response. Check whether apparently independent variables are actually correlated by conservation or control logic. Treat a high-sensitivity variable as a candidate for better measurement. If the result requires a parameter measured by the same output that is being predicted, the model is partly circular and its validation requires an independent observation. **Assumed numerical case:** At rho=1.2 kg/m3, v=25 m/s and K=2, estimated loss is 750 Pa.

Worked Engineering Derivation:

**Calculation walkthrough:** Using K=2, density 1.2 kg/m³ and velocity 25 m/s, calculate Δp = 2(1.2)(25²)/2 = 750 Pa, or 0.75 kPa. Doubling velocity to 50 m/s in this fixed-K approximation quadruples the predicted loss. The quadratic relationship is a local model; the real K may change with flow regime.
