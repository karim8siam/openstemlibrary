Solved Problem Example 5.1: Calculation & Verification: Internal Combustion Engines — U05-L01

Problem Statement: Use `Fuel required per cycle = trapped_air_mass / commanded_AFR on a consistent mass basis.` as the initial closure relation. It is tempting to interpret the number as a design guarantee; instead define a reference operating point, perturb each independent input separately and observe the output response. Check whether apparently independent variables are actually correlated by conservation or control logic. Treat a high-sensitivity variable as a candidate for better measurement. If the result requires a parameter measured by the same output that is being predicted, the model is partly circular and its validation requires an independent observation. **Assumed numerical case:** With 0.0005 kg air per cycle and AFR=14.7, fuel target is about 34 mg per cycle.

Worked Engineering Derivation:

**Calculation walkthrough:** At 0.0005 kg trapped air per induction event and commanded mass AFR 14.7, divide 0.0005/14.7 = 3.401×10⁻⁵ kg fuel. This equals 34.0 mg. For injection duration, additional injector flow calibration and dead-time compensation are required; the mass calculation by itself does not give a pulse width. Interpret the result, including failures **Critical interpretation:** Commanded pulse width does not equal delivered mass at all injector pressures or voltages. A misleading numerical result can arise even when the arithmetic is perfect: the problem may be a wrong system boundary, an inappropriate reference property, a time-averaged signal used for a crank-angle event, or an unrecorded controller response. State which of those failure mechanisms is most likely here. Think about the change that would be observed in cylinder pressure, exhaust temperature, manifold state, or brake output if the explanatory mechanism were genuinely active rather than merely correlated with an unrelated change. **Conservation audit:** Start by marking the system boundary on a sketch. Separate fuel energy entering the cylinder from indicated work on the piston and brake work at the shaft. A computed improvement that violates energy conservation is a mistake, not a new engine phenomenon. Where an experimental result seems to contradict the calculation, investigate calibration, hidden storage, auxiliary loads and the interpretation of reference conditions before adding complexity to the model. Solved Problem Example 5.3: Calculation & Verification: Internal Combustion Engines — U05-L03

Problem Statement: The smallest useful model is `Torque error e = T_requested - T_estimated, with limits supplied by subsystem constraints.`. Write it first in symbols because symbols expose which quantities are inputs and which are derived. Conduct a dimensional check. For example, an energy rate must have dimensions of power, and a dimensionless efficiency must not quietly carry a pressure unit. Then inspect the limiting cases. A vanishing input, a zero flow or an impossible temperature ratio should trigger a validity warning rather than a numerically polished answer. The equation belongs to the assumptions stated with it, not to every engine. **Assumed numerical case:** If request is 220 N m and permitted limit is 180 N m, the delivered target must be bounded at 180 N m.
