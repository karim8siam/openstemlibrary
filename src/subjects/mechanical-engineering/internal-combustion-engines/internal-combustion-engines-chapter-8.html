Solved Problem Example 8.1: Calculation & Verification: Internal Combustion Engines — U08-L01

Problem Statement: Use `A consistent energy comparison is chemical input = fuel mass * specified lower heating value.` as the initial closure relation. It is tempting to interpret the number as a design guarantee; instead define a reference operating point, perturb each independent input separately and observe the output response. Check whether apparently independent variables are actually correlated by conservation or control logic. Treat a high-sensitivity variable as a candidate for better measurement. If the result requires a parameter measured by the same output that is being predicted, the model is partly circular and its validation requires an independent observation. **Assumed numerical case:** At 0.010 kg of fuel with assumed LHV 120 MJ/kg, input is 1.2 MJ before conversion losses.

Worked Engineering Derivation:

**Calculation walkthrough:** With an assumed lower heating value of 120 MJ/kg and fuel mass 0.010 kg, the chemical input is 120×0.010 = 1.2 MJ. This is not the amount of brake work: conversion efficiency and storage auxiliaries remain. The assumed LHV should never be interpreted as a property value that applies to all fuel blends or storage conditions. Interpret the result, including failures **Critical interpretation:** Hydrogen operation can still form thermal NOx in air and requires stringent leak management. A misleading numerical result can arise even when the arithmetic is perfect: the problem may be a wrong system boundary, an inappropriate reference property, a time-averaged signal used for a crank-angle event, or an unrecorded controller response. State which of those failure mechanisms is most likely here. Think about the change that would be observed in cylinder pressure, exhaust temperature, manifold state, or brake output if the explanatory mechanism were genuinely active rather than merely correlated with an unrelated change. **Conservation audit:** Start by marking the system boundary on a sketch. Separate fuel energy entering the cylinder from indicated work on the piston and brake work at the shaft. A computed improvement that violates energy conservation is a mistake, not a new engine phenomenon. Where an experimental result seems to contradict the calculation, investigate calibration, hidden storage, auxiliary loads and the interpretation of reference conditions before adding complexity to the model. Solved Problem Example 8.3: Calculation & Verification: Internal Combustion Engines — U08-L03

Problem Statement: The smallest useful model is `CHP utilization = (useful electric output + useful recovered heat)/fuel input on a common energy basis.`. Write it first in symbols because symbols expose which quantities are inputs and which are derived. Conduct a dimensional check. For example, an energy rate must have dimensions of power, and a dimensionless efficiency must not quietly carry a pressure unit. Then inspect the limiting cases. A vanishing input, a zero flow or an impossible temperature ratio should trigger a validity warning rather than a numerically polished answer. The equation belongs to the assumptions stated with it, not to every engine. **Assumed numerical case:** For 100 kW fuel input, 32 kW electric and 40 kW useful heat, utilization is 72%.

Worked Engineering Derivation:

**Calculation walkthrough:** For fuel input 100 kW, useful electric output 32 kW and useful heat delivered 40 kW, combined utilization is (32+40)/100 = 72%. The uncounted 28 kW includes losses in this simplified boundary. Heat dumped to the environment is not useful heat, regardless of whether a thermal exchanger could theoretically intercept it.
