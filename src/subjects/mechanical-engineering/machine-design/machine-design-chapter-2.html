Solved Problem Example 2.1: Calculation & Verification: Torsional shear in solid shafts

Problem Statement: An engineering practitioner analyzes a mechanical system governed by **Torsional shear in solid shafts** under steady operational loading.

Worked Engineering Derivation:

**Question:** Calculate nominal torsional shaft stress using T=180 N m, diameter=0.032 m. Using the explicit relationship for this simplified case, the arithmetic is `16*180/(pi*0.032**3)/1e6`. The computed result is **27.98 MPa**. This is a synthetic, rounded result; it is not a measured or independently certified design capacity. Recalculate with an independent calculator before passing it into a later sizing step. A result outside a plausible physical range is evidence that units or assumptions may be wrong, not automatically a new discovery. **Interpretation:** The number answers only the posed arithmetic question. A design release would require a defined allowable, actual load spectrum, material condition, geometric tolerances and a standard-appropriate assessment. The main danger in this particular lesson is that calculating with diameter in millimetres while using N*m without conversion creates a billion-fold scale error. A responsible notebook records both the numerical output and the reason why the model is incomplete.
